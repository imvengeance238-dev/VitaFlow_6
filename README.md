# Vita Flow

Open in Android Studio (File > Open), sync, run. Package app.vitaflow.com, minSdk 31.

Flow: sign in -> detailed profile questions -> roadmap -> app.
Tabs: Home, Fitness (workout, diet), Tasks, Max (chat), Profile (gear = settings).
Max is text chat with app control (open screens, change theme, tasks, workouts, meals). A round Max button
on every screen opens a compact chat, so the conversation follows you.
Max AI is online: set it in Settings > Max AI (own backend in /backend, or a Gemini key). The phone model is an optional fallback.
Voice code is still in the project but switched off.
